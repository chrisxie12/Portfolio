## Built with

Plain HTML, CSS and JavaScript. No build step.

```
index.html
css/style.css
js/main.js
```

## Run locally

Open `index.html` in a browser, or:

```bash
npx serve .
```

## Deploy

Settings → Pages → Deploy from branch → `main` / root.
